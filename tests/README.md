# Автотести

| Рівень                  | Інструмент                                             | Команда                  |
| ----------------------- | ------------------------------------------------------ | ------------------------ |
| Unit                    | Vitest                                                 | `npm run test:unit`      |
| API                     | Vitest + supertest                                     | `npm run test:api`       |
| E2E (smoke)             | Playwright, проєкти `desktop-chrome` і `mobile-chrome` | `npm run test:e2e`       |
| Ручні/регресійні запити | Postman                                                | див. `postman/README.md` |

`npm test` запускає unit і API разом.

## Структура

- `helpers/testApp.js` — фабрика застосунку для API-тестів: in-memory SQLite (`schema.sql` + `seed.sql`) і тимчасова тека для фото на кожен тестовий файл; `cleanup()` закриває БД і видаляє теку. Також валідні поля форми, multipart-хелпер і перевірка формату помилки.
- `helpers/images.js` — крихітні PNG/JPEG, згенеровані в коді (бінарні файли не комітяться), і PNG заданого розміру для перевірки межі 5 МБ.
- E2E працюють з окремою БД `data/e2e.db`, яку `playwright.config.js` перестворює перед стартом сервера. Тест зі створенням ідеї сам її видаляє разом із фото.
